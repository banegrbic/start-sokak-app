## 🇷🇸 O projektu (srpski)

**start.sokak.app** je brza, responzivna, dark/light tema start stranica
sa preko 100 linkova u 12+ kategorija (mediji, pretraga, AI alati,
društvene mreže, alati, zabava, multimedija, domaći servisi).

### 🇷🇸 Ključne funkcionalnosti

- ⭐ **Favoriti** — prevuci link u "Moji linkovi" kategoriju
- ➕ **Custom linkovi** — dodaj svoje linkove
- 🌓 **Dark / light tema** — automatski pamti izbor
- 🔍 **Live pretraga** — filter po nazivu ili URL-u
- 👁 **Sakrij kategorije** — svaka ima 👁 dugme
- 📱 **Responzivan** — radi na desktopu, tabletu, mobilnom
- 🔀 **Drag & drop** — menjaj redosled kategorija
- 🍺 **Donacija** — opciono PayPal dugme (lako se menja)
- 💡 **Suggest link** — PHP backend šalje email administratoru
- ⚖️ **Privacy-first** — NEMA analytics po defaultu

### 🇷🇸 Quick start

```bash
git clone https://github.com/banegrbic/start-sokak-app.git
cd start-sokak-app
# Otvori index.html u browseru — radi!
```

Kompletna uputstva (konfiguracija, deployment, API setup) su u
[README.md](README.md).

## 🇬🇧 About this project (English)

**start.sokak.app** is a fast, responsive, dark/light themed start page
with 100+ bookmarks in 12+ categories (media, search, AI tools, social
networks, utilities, entertainment, multimedia, local services).

### 🇬🇧 Key features

- ⭐ **Favorites** — drag any link into "My Links" category
- ➕ **Custom links** — add your own links
- 🌓 **Dark / light theme** — remembers your choice
- 🔍 **Live search** — filter by name or URL
- 👁 **Hide categories** — each has a 👁 button
- 📱 **Responsive** — works on desktop, tablet, mobile
- 🔀 **Drag & drop** — reorder categories
- 🍺 **Donate** — optional PayPal button (easy to replace)
- 💡 **Suggest link** — PHP backend sends email to administrator
- ⚖️ **Privacy-first** — NO analytics by default

### 🇬🇧 Quick start

```bash
git clone https://github.com/banegrbic/start-sokak-app.git
cd start-sokak-app
# Open index.html in your browser — it works!
```

Complete instructions (configuration, deployment, API setup) are in
[README.en.md](README.en.md).
